# 使用说明

## 在线体验

打开 [在线工作台](https://methodatlas.64-90-4-239.sslip.io/)，使用项目方提供的访问凭据登录。在线实例的数据与本机安装分别保存。视频可直接从仓库首页观看或下载。

## 创建项目与配置模型

在首页新建研究项目，按主题命名。各项目分别保存资料、对话和成果。左侧为文献，中间为研究对话，右侧为成果；分隔线可以拖动。

打开右上角设置，添加 DeepSeek 或 OpenAI Chat Completions 兼容连接，填写模型、地址和自己的密钥，点击“测试能力”。在输入框选择可用模型及推理偏好。密钥保存在本机后台，不随成果导出。

## 添加与阅读资料

点击“添加来源”，上传 PDF、粘贴单篇论文链接，或输入标题和原文文字。PDF 单个最多 40 MB，每批最多 20 项、120 MB，批量导入逐项显示结果。

点击资料阅读正文，核对版面、公式或图像时切换原 PDF。只有摘要或元数据不等于已取得全文；无法自动下载时可手动补充 PDF。

勾选资料表示研究重点，“仅这些”严格限制范围；未勾选时可使用项目内资料。

## 对话与引用

比较方法、解释段落、定位原文，或明确要求生成研究成果。普通讨论不会自动生成文件。点击引用回到所用文献版本的对应原文；图像解读需要同时核对原图。

研究中发送新要求会停止同一对话中的旧任务并调整方向，已有成果保留。执行记录可以展开查看。模型或来源请求失败时，按页面提示重试或调整要求。

## 成果与版本

例如：“把这三篇论文整理成方法比较报告，保留引用。”在右侧预览、切换版本和下载。

- 研究报告：支持生成、修订和对应格式导出。
- 论文写作：在 Studio 新建文稿，人工编辑或请求 AI 起草、润色。AI 修改先成为提案，接受后才保存为正式版本。
- 科研图表：先导入真实 CSV 数据，再说明图表类型和比较目标。
- 组会汇报：指定材料和要求生成 PPTX，来源随成果保留。
- 关系图谱：根据材料生成带证据的论文关系图，可以修订并导出独立 HTML。

各成果可导出的格式以页面按钮为准。恢复历史会追加版本；不能追回他人已经下载的副本。

## 持续研究

个人研究方法可从已完成回答中提炼，预览确认后保存和复用。论文订阅定时检索，候选论文经确认后进入资料库。研究记录回顾日、周、月的实际活动并保留人工修订。

定时任务需要本地后端持续运行；模型、网络与原始资料可用性会影响结果。

## 远程实验

配置自己的服务器和项目目录，核对计划、命令和授权范围后执行。状态、日志与选定结果可以回收为研究材料。该功能需要实际计算环境，不是本地安装后自动具备的能力。

## 验收一条完整流程

导入论文 → 提问 → 点击原文引用 → 生成报告 → 修订 → 下载。确认下载文件可打开，旧版本仍可查看，引用指向当时使用的资料版本。
