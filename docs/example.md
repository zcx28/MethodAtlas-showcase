# 评委体验路线：从文献到共同研究

建议先走一次个人研究闭环，再用两个独立账号检查协作。在线项目由项目方提供，自己部署时先完成模型与认证配置。

## 1. 导入资料并核对依据

新建“机器人模仿学习”项目，在论文链接入口逐行添加：

```text
https://doi.org/10.15607/rss.2023.xix.026
https://doi.org/10.15607/rss.2023.xix.016
https://doi.org/10.15607/rss.2024.xx.067
```

对应 Diffusion Policy、Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware、3D Diffusion Policy。论文版权属于各自作者与出版方；仓库只提供入口。下载失败时上传自己取得的 PDF，只有摘要时不要将其当成全文。

勾选资料，发送：

> 比较这些方法的观测输入、动作生成方式、适用条件和局限。只使用所选资料，每个关键判断附原文引用；没有全文支持的部分明确说明。

点击一个引用，核对其原文与版本。选中段落打开 AI 对话浮窗，追问“这个实验在哪些条件下成立？”检查历史列表、移动与窗口大小调整。

## 2. 修订并交付成果

发送：“把刚才的比较整理成组会报告，保留引用，不补造实验数字。”在右侧核对成果，再请求补充比较条件和目前不能下结论的部分。

打开论文编辑器建立提纲，体验手动编辑、自动保存和 AI 修改提案。接受提案更新草稿；点击存档生成历史节点。下载可用格式，确认文件可以打开、来源可以回查。

## 3. 两位成员接续工作

1. 项目负责人邀请另一个邮箱，成员验证邮箱并接受邀请。
2. 负责人建立“核对比较条件”研究任务，分配给成员并关联一份文献或成果。
3. 成员在论文选区评论，@ 负责人；负责人回复并解决讨论。
4. 将经确认的判断保存为项目知识，查看项目动态与通知。
5. 成员开启私人探索；负责人核对无法读取私人正文。需要共享时，成员预览后主动发布独立笔记。

## 观察什么

- 结论是否附有实际资料依据，而不是只有一段流畅回答。
- 成果草稿、手动存档和 AI 提案是否区分清楚。
- 资料、任务和评论是否能让另一位成员继续研究。
- 私人内容与项目共享内容是否按成员权限隔离。

这是一条可复现的体验路线，不是固定模型答案，也不代表这些研究方法已经由作品验证。模型、资料来源和可选服务会影响运行结果。
