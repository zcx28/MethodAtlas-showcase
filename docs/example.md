# 体验案例：机器人模仿学习

研究问题：几种机器人模仿学习方法如何表达输入、生成动作，比较时需要注意什么条件？

新建“机器人模仿学习”项目，在“添加来源 → 论文链接”逐行粘贴：

```text
https://doi.org/10.15607/rss.2023.xix.026
https://doi.org/10.15607/rss.2023.xix.016
https://doi.org/10.15607/rss.2024.xx.067
```

分别对应 Diffusion Policy、Learning Fine-Grained Bimanual Manipulation with Low-Cost Hardware、3D Diffusion Policy。论文属于各自作者及出版方，本仓库提供入口，不附带整篇论文副本。下载失败时可以补充自己取得的全文。

1. 勾选三篇资料：“比较这三篇论文的观测输入、动作生成方式、适用条件和局限。只使用这些资料，每个关键判断附原文引用。”
2. 点击引用核对结论，继续追问：“这处结论来自哪个实验或段落？请定位原文。”
3. 请求成果：“把刚才的比较整理成组会报告，保留引用，不补造实验数字。”
4. 请求修订：“补充比较条件和目前不能下结论的部分。”
5. 在成果区比较版本，下载并打开最终文件。

这是可复现的体验步骤，不是固定的模型答案。本地新安装可按此创建案例，也可使用自己的资料。在线体验的数据以已部署实例为准。
