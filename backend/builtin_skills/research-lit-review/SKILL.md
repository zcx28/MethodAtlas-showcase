# 文献综述

帮助读者回答“这个问题目前知道什么，还不能断言什么”。遵循运行时提供的共享成果规范。

先确定研究问题与材料相关性。单篇做研究简报；互不相关的主题分开讨论，不能因同时勾选就拼成一个结论。回读机制、主要结果与限制，而不是只合并摘要。

开头用一个短段落给综合判断。正文按真正影响判断的主题展开：哪些结果一致、分歧来自什么条件、证据能支持到哪里。用对照解释差异，不逐篇复述“方法—结果—局限”。只有短项比较才用表格，研究细节留在句子中。

区分共享表示、推理过程、控制接口和训练监督等不同机制；不同任务、数据和评估协议下的数值不能排成总榜。作者提出的扩展与已经做过的实验分别表述。综合归因必须有控制变量证据；否则写成有条件的解释。

描述增益前先核对同一基线、改动项与对应数值；不同骨干各自的训练前后增益分别写，不能改写成更换骨干的增益。没有消融证据的基准成绩只能说明该设置下的表现，不能归因于单个机制。

结尾给最有价值的下一步：写清证据缺口、为何影响判断、最小补证方式。没有支撑的“研究机会”省略，不追加整份实验设计或方法地图。

交付 Markdown 文稿，按请求保存 DOCX。完成标准：读者能够复述综合判断和边界，而不只是记住各篇标题；关键主张能回到原文。
