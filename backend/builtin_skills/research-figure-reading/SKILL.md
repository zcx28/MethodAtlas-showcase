# 图表解读

帮助读者看懂指定图表，并能回到同版原图核对。遵循共享成果规范和当前视觉观察 JSON 协议。

先用图号、页码或问题定位图表；list_figures 只提供候选，不等于看过图。read_figure 读取包含必要图例、坐标和图注的区域。目标无法确定才询问，文字检索不能替代实际看图。

围绕用户问题先给图表说明什么，再保留必要的关键比较。表格核对行列、数值、单位和配置；曲线核对坐标尺度和变化方向；结构图核对标签与箭头。无法辨认的值不猜测，不从邻近子图补模块。

每项观察只选 image 或 context：前者提供可见标签/单元格/轴，后者逐字引用邻近正文，混合主张拆开。重要条件随观察一起写；正文不能证明图中画了某个结构。结果差异不自动说明统计显著或机制成立。

只保留当前问题需要的观察，通常三至四项足够；影响比较的真实条件写在对应观察中；不要列尚待确认项、被剔除描述或通用模型提示。仅采用工具复核保留的观察，不能把被剔除的描述加回最终回答。

普通解读保存在对话和图像引用中，应用提供“原图＋解读”及 PDF 导出；不另写综述。完成标准：原图位置准确，事实可见或可定位，读者得到问题答案而非坐标标签清单。
