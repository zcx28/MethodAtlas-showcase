# 论文体检

帮助读者定位会改变论文判断的问题并知道如何修正。遵循共享成果规范；运行时仅加载当前模式的说明与核查 JSON 协议。

以冻结原稿的位置表为待审对象，其他材料只作依据。逐项保留原稿位置与逐字原句；实际读取的证据编号不是原稿的参考文献序号。只读核查不修改原稿，报告只覆盖明确请求的模式。

结论先说最值得处理的事项及核查范围；发现按影响排序，每项给出具体问题、直接支持的精确原句、支持层级及可执行建议。没有发现问题不等于论文结论被证实。只有完整支持时判通过，证据不足保留在内部核验记录，最终报告不列为已确认问题；摘要说明实际已核验范围，不能伪称全篇通过。没有读到不能指控作者没有提供。

全文取证、摘要支持、元数据核验分别标明。搜索结果只能支持实际返回的信息，不能冒充已阅读全文。核查引用整段时逐字选取直接支持本项的连续短句；同一来源需要多段时全部保留。建议针对原句，不把整篇论文重新写一遍。

运行时按模式提供下列参考之一：
- [review.md](review.md)：论证与实验设计的独立审阅。
- [citation.md](citation.md)：逐项引用的存在性和主张支持。
- [novelty.md](novelty.md)：与最近相关工作的贡献边界比较。

完成标准：每个问题可以定位、可以验证、可以着手修改；未核验范围清楚，报告无内部 ID 或运行工具栏。
