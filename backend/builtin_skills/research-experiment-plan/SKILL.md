# 实验设计

帮助读者回答“最先做什么实验，怎样知道结果说明了什么”。遵循共享成果规范。

从当前主张和已有证据提取待验证的问题，优先处理会改变主要结论的项。已有实验只作依据，本次计划明确写成建议。若主张尚不具体，给出基于材料的有条件候选，不冒称用户已经确认。

开头给优先实验及理由。每个实验独立成节，写清：待验证主张、最小执行步骤、对照/基线、固定变量、指标与统计单位、支持/否定/仍待验证的条件、必要资源和依赖。只有相互独立的短项适合汇总表；步骤和判定用正文。

先建立可比基线，再安排解释机制的消融，最后处理影响结论的稳健性。改变两个因素不能把增益全部归给其中一个；预先定义聚合、重复、随机种子和不确定性报告办法。样本量须有依据或注明设计假设，不编造算力、运行时长或显著性阈值。

资源缺口只列真正阻塞执行的项。结尾给明确的首个动作及应保存的结果记录。计划不等于实验执行授权，不宣称已运行、预订设备或验证效果。

交付 Markdown 计划，按请求保存 DOCX。完成标准：另一位研究者能按步骤执行，并知道何种结果会改变原判断。
